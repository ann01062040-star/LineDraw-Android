# LineDraw Android 獨立版隱私說明

更新日期：2026-10-08。適用版本：0.1.3-standalone。

## 本機資料

App 將同步後的活動清單、連結、抽選批次、抽選與手動完成紀錄、本機設定檔、篩選偏好、使用聲明確認版本及操作診斷保存在手機內。獨立版不要求網站帳號、VIP 或會員權杖，未配置將這些資料自動上傳至維護者伺服器的功能，也未整合廣告或使用行為分析 SDK。

操作診斷記錄批次狀態、步驟、時間及原因；診斷預覽亦列出 Android API、手機廠牌與型號。App 啟動時清理超過 30 天的操作診斷；抽選紀錄不會因此一併刪除。此清理不是精確到時自動執行的計時服務。

## 無障礙服務

使用者啟用服務並主動開始批次後，App 會讀取目前畫面的文字、按鈕、輸入欄位及視窗資訊，用於判斷活動頁、等待載入及執行已選活動的加入好友／抽選操作。遇到非預期 App、登入、驗證碼等需要本人處理的情況會暫停。

畫面內容供當下流程判斷；App 不以建立聊天紀錄為目的，也不把原始畫面文字保存到操作診斷。無障礙權限本身具備讀取畫面的能力，請只對你信任的安裝來源啟用。可隨時透過浮動列停止批次，或在 Android 設定中關閉服務。

## 網路連線與外部服務

同步時 App 會讀取 Funbox 的公開頁面；解析活動連結時可能連線至 lin.ee、LIFF 及該連結允許的重新導向位置。手動開啟或自動抽選則透過 LINE App 執行。

外部服務可能取得正常連線所需的 IP、HTTP 請求資訊；LINE 內的帳號及抽選行為由 LINE 與活動服務處理。它們依各自的服務條款與隱私政策運作。「資料保存在本機」不代表使用過程完全不連網。

## 分享與問題回報

只有按下「設定 → 預覽診斷紀錄 → 分享」，並自行選擇分享對象時，App 才將診斷文字交給 Android 分享功能。分享前請檢查內容；接收資料的其他 App 或服務有各自的資料處理方式。

GitHub Issues 不會由 App 自動建立。若你自行回報問題，內容將依該倉庫可見性及 GitHub 規則呈現。請勿附上 LINE 登入資訊、驗證碼、聊天內容、網站權杖或簽署金鑰。

## 清除與移除

可在診斷預覽中按「清除診斷」。若要清除所有本機資料，使用 Android「App 資訊 → 儲存空間 → 清除資料」，或移除 App；這些操作也會刪除抽選紀錄及設定，請確認後再做。目前沒有跨 VIP 版／獨立版的資料轉移功能。

App 關閉 Android 自動備份及裝置移轉備份。你自行匯出的內容、GitHub 回報及外部服務保存的資料，不會因移除 App 而自動刪除。
